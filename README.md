# Projeto de Habilidades no DOM

Este projeto foi criado com o objetivo de ajudar a desenvolver e aprimorar habilidades no uso do **DOM** (Document Object Model) em JavaScript.

## Descrição

O projeto é simples e consiste em um arquivo `index.html` que interage com o DOM. O código foi elaborado para que você possa praticar manipulações e interações básicas com elementos HTML utilizando JavaScript.

## Como executar

### Pré-requisitos

- Um navegador de internet (como Google Chrome, Firefox, etc.)

### Passos

1. **Clone ou baixe o repositório:**

   Se você deseja baixar o projeto, pode fazer isso de duas maneiras:

   - **Via Git** (recomendado):
     ```bash
     git clone https://github.com/ElielSilva/project-pixels-art.git
     ```

   - **Ou baixe o arquivo ZIP** diretamente do GitHub, descompacte e extraia os arquivos.

2. **Abra o arquivo `index.html` no seu navegador:**

   Basta abrir o arquivo `index.html` no seu navegador preferido. Clique com o botão direito sobre o arquivo e escolha "Abrir com" > [seu navegador].

3. **Interaja com a página:**

   A página interage com o DOM e você pode modificar e testar o comportamento de elementos HTML. Sinta-se à vontade para editar o código JavaScript e o HTML para ver os efeitos das mudanças no navegador.

## Tecnologias utilizadas

- **HTML5**: Estrutura básica da página.
- **CSS**: Estilo básico para apresentação.
- **JavaScript**: Para manipulação do DOM e interações dinâmicas.

## Objetivo do projeto

Este projeto tem o propósito de permitir que os desenvolvedores iniciantes pratiquem a manipulação do DOM de maneira simples e eficiente, utilizando JavaScript para interagir com a página HTML.
